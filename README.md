# FitAdapt — Техническая документация

Документация платформы адаптивных тренировок FitAdapt, реализованная по принципу **docs as code**.
# Technical documentation for your product

Проект технической документации, оформленный по подходу docs as code на базе Docusaurus и опубликованный через GitHub Pages.

## Что внутри

.
├── my-site/                    # Docusaurus-сайт с технической документацией
│   ├── docs/                   # Основные разделы документации
│   ├── static/                 # Статические ресурсы
│   ├── src/                    # Служебные файлы Docusaurus
│   ├── docusaurus.config.js    # Конфигурация сайта
│   ├── sidebars.js             # Структура бокового меню
│   ├── package.json            # Скрипты и зависимости
│   └── README.md               # Описание проекта
├── .github/
│   └── workflows/              # Автодеплой GitHub Pages
└── build/                      # Собранная статическая версия сайта

## Структура документации

- Обзор проекта
- Архитектура
- Доменная модель
- API

- Алгоритмы
- Интеграции
