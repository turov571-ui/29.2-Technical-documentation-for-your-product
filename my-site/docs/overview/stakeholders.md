# Стейкхолдеры

## Внутренние стейкхолдеры

| Роль | Интересы | Влияние |
|---|---|---|
| **Команда разработки** | Понятные требования, стабильный API-контракт | Высокое |
| **Product Owner** | Ценность для пользователя, скорость выхода на рынок | Высокое |
| **Системный аналитик** | Полнота спецификации, отсутствие белых пятен | Высокое |

## Внешние стейкхолдеры

| Роль | Интересы | Влияние |
|---|---|---|
| **Клиент фитнес-клуба (CLIENT)** | Простой ввод данных, понятная рекомендация, ощущение прогресса | Высокое |
| **Тренер (TRAINER)** | Быстрый обзор состояния клиентов, своевременные уведомления | Высокое |
| **Фитнес-оператор (партнёр)** | Интеграция через API, white-label, предсказуемые затраты по MAU | Высокое |
| **HR / корпоративный велнес** | Отчётность, данные по вовлечённости, соответствие 152-ФЗ | Среднее |

## Приоритет

Клиент и Тренер — основные пользователи системы. Их потребности формируют функциональные требования в первую очередь.
