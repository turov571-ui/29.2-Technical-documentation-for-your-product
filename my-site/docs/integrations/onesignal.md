# Интеграция с OneSignal

OneSignal используется как внешний провайдер уведомлений. Он маршрутизирует push через FCM и APNs и предоставляет аналитику доставки.

## Назначение интеграции

- Доставка push-уведомлений тренерам при низком Readiness Index клиента
- Унификация каналов: один HTTP-запрос из n8n вместо отдельной логики для FCM и APNs
- Retry при временной недоступности канала — на стороне OneSignal
- Дедупликация через `external_id` — предотвращение дублей при повторных вызовах

## Что уходит из проекта при переходе на OneSignal

| Было в n8n | Стало |
|---|---|
| Хранение FCM-токенов и Telegram chat_id | OneSignal хранит сам |
| Retry-логика при сбое канала | OneSignal делает сам |
| Переключение на резервный канал | Настраивается в UI OneSignal |
| Таблица статусов отправок | Видна в дашборде OneSignal |

## Пример вызова из n8n

HTTP Request node, `POST https://onesignal.com/api/v1/notifications`:

```json
{
  "include_external_user_ids": ["trainer-uuid"],
  "external_id": "deduplication-key-from-kafka-event",
  "contents": {
    "ru": "⚠️ Иван Иванов — индекс готовности 3.1. Требует внимания."
  },
  "channel_for_external_user_ids": "push"
}
```

## Тарифный план

Для старта используется **бесплатный план** (до 10 000 подписчиков). В типичном фитнес-клубе тренеров значительно меньше этого числа. При росте — переход на платный тариф (~$9/мес).
