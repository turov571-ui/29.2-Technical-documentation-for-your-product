# Алгоритм Readiness Index

Readiness Index — агрегированный показатель готовности клиента к тренировочной нагрузке. Используется как основа для DMN-правил выбора рекомендации.

## Входные данные

| Параметр | Диапазон | Вес в формуле |
|---|---|---|
| `sleepQuality` | 1–10 | 35% |
| `energyLevel` | 1–10 | 30% |
| `mood` | 1–10 | 20% |
| `weight` | 20–300 кг | 15% (через WeightScore) |

## Формула расчёта

```text
ReadinessIndex =
  0.35 × SleepQuality +
  0.30 × EnergyLevel  +
  0.20 × Mood         +
  0.15 × WeightScore
```

Итоговый индекс нормируется в диапазон **0–10**.

## Интерпретация результата

| Диапазон | Интерпретация | Действие |
|---|---|---|
| 0.0 – 3.9 | Низкая готовность 🔴 | Уведомить тренера |
| 4.0 – 6.9 | Средняя готовность 🟡 | Поддерживающая нагрузка |
| 7.0 – 10.0 | Высокая готовность 🟢 | Полноценная тренировка |

## Где выполняется расчёт

Расчёт происходит в **n8n workflow** после получения события `health.data.saved` из Kafka. Результат записывается в таблицу `recommendations` через внутренний вызов `POST /recommendations` (backend API).
