## Роль: CLIENT — сценарий «Ввод метрик и получение рекомендации»

### Экран `/health` — Ввод данных о здоровье

```
┌─────────────────────────────────────────┐
│  📊 Моё состояние сегодня               │
│─────────────────────────────────────────│
│  Вес (кг):        [  75.5  ]            │
│  Уровень энергии: [  7  ] /10           │
│  Качество сна:    [  6  ] /10           │
│  Настроение:      [  8  ] /10           │
│                                         │
│          [ Отправить ]                  │
└─────────────────────────────────────────┘
```

**Что отображается:** форма ввода четырёх метрик с предзаполнением из последней записи.

**Действия пользователя:**
- При открытии → `GET /health-profile` (предзаполнение)
- Нажатие «Отправить» → `POST /health-data` с `X-Idempotency-Key`
- После успешного сохранения → переход на `/recommendation`

### Экран `/recommendation` — Рекомендация по тренировке

```
┌─────────────────────────────────────────┐
│  🏃 Твоя тренировка на сегодня          │
│─────────────────────────────────────────│
│  Индекс готовности:  7.4 / 10  ████░    │
│                                         │
│  Тип тренировки:     CARDIO             │
│  Интенсивность:      MEDIUM             │
│  Длительность:       45 мин             │
│                                         │
│  «Показатели в норме.                   │
│   Кардио-нагрузка оптимальна.»          │
└─────────────────────────────────────────┘
```

**Что отображается:** Readiness Index, тип/интенсивность/длительность тренировки, текстовое обоснование.

**Действия пользователя:**
- При открытии → `GET /recommendation/{clientId}` (clientId берётся из JWT)

## Роль: TRAINER — сценарий «Просмотр клиентов»

### Экран `/trainer/clients` — Список клиентов

```
┌────────────────────────────────────────────────────────┐
│  👥 Мои клиенты                    [sort: индекс ↓]    │
│────────────────────────────────────────────────────────│
│  Имя           │ Индекс │ Тренировка  │ Обновлено      │
│────────────────┼────────┼─────────────┼────────────────│
│  Иван Иванов   │  8.2   │ STRENGTH    │ сегодня, 09:00 │
│  Мария Петрова │  7.4   │ CARDIO      │ сегодня, 08:30 │
│  Алекс Смирнов │  3.1 🔴│ REST        │ вчера, 22:00   │
│────────────────────────────────────────────────────────│
│  < 1 2 3 ... >                                         │
└────────────────────────────────────────────────────────┘
```

**Что отображается:** таблица клиентов с индексами, типом тренировки и датой последней записи.

**Действия пользователя:**
- При открытии → `GET /trainer/clients?page=0&size=20&sort=readinessIndex,desc`
- Клик по строке → переход на `/trainer/clients/{clientId}`

### Экран `/trainer/clients/{clientId}` — Карточка клиента

```
┌─────────────────────────────────────────┐
│  ← Назад  │  Иван Иванов               │
│─────────────────────────────────────────│
│  Readiness Index:  8.2 / 10  █████████░ │
│  Последняя запись: сегодня, 09:00       │
│─────────────────────────────────────────│
│  Рекомендация:                          │
│  STRENGTH · HIGH · 60 мин               │
│─────────────────────────────────────────│
│  История метрик (30 дней):              │
│  [  График динамики индекса  ]          │
└─────────────────────────────────────────┘
```

**Что отображается:** профиль клиента, индекс, рекомендация, график истории.

**Действия пользователя:**
- При открытии → `GET /trainer/clients/{clientId}?historyDays=30`
