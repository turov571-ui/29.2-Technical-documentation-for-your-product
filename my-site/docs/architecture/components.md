# Компоненты системы

## Backend API (Spring Boot)

Основная точка входа для мобильного приложения. Отвечает за аутентификацию, REST API, публикацию событий в Kafka и персистентность в PostgreSQL.

**Технологии:** Java 21, Spring Boot 3, Spring Security, Spring Data JPA

## n8n (Воркфлоу-движок)

Self-hosted инструмент автоматизации. Подписывается на Kafka-топик `health.data.saved`, рассчитывает Readiness Index, вызывает DMN-движок и отправляет HTTP-запрос в OneSignal при срабатывании порога.

## PostgreSQL

Основная реляционная БД. Хранит пользователей и роли, записи о здоровье, рекомендации, связи тренер–клиент.

## Kafka

Асинхронная шина событий.

| Топик | Producer | Consumer | Событие |
|---|---|---|---|
| `health.data.saved` | Backend API | n8n | Сохранена запись метрик |
| `notification.send` | n8n | Notification Worker | Нужно отправить уведомление |

## OneSignal

Внешняя платформа уведомлений. Берёт на себя маршрутизацию каналов, хранение токенов, retry и аналитику доставки.
