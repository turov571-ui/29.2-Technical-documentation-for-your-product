# Контекстная диаграмма системы

## Описание

FitAdapt состоит из нескольких взаимодействующих компонентов. На контекстном уровне система принимает данные от мобильного приложения и взаимодействует с внешними сервисами уведомлений.

## Компоненты и внешние системы

```
┌─────────────────────────────────────────────────────────────┐
│                        FitAdapt                             │
│                                                             │
│  ┌──────────┐    ┌──────────┐    ┌──────────────────────┐  │
│  │ Mobile   │    │ Backend  │    │       n8n            │  │
│  │   App    │◄──►│  API     │◄──►│  • Readiness Index   │  │
│  │(iOS/And) │    │(Spring)  │    │  • DMN-правила       │  │
│  └──────────┘    └────┬─────┘    └──────────┬───────────┘  │
│                       │                     │               │
│                  ┌────▼─────┐         ┌─────▼──────┐       │
│                  │PostgreSQL│         │   Kafka    │       │
│                  └──────────┘         └─────┬──────┘       │
│                                             │               │
└─────────────────────────────────────────────┼───────────────┘
                                              │
                                    ┌─────────▼──────────┐
                                    │     OneSignal      │
                                    │  Push-уведомления  │
                                    └────────────────────┘
```

## Взаимодействие с внешними системами

| Система | Тип | Назначение |
|---|---|---|
| **FCM (Firebase)** | Внешний сервис | Push на Android |
| **APNs (Apple)** | Внешний сервис | Push на iOS |
| **OneSignal** | Внешний сервис | Оркестрация уведомлений |

## Граница системы

**Внутри FitAdapt:** мобильное приложение, Backend API, n8n, PostgreSQL, Kafka.

**За пределами:** OneSignal, FCM/APNs, OAuth-провайдер.
