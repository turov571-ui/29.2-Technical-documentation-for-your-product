# Стратегия платформизации

## Что продаётся как платформа

Основная ценность FitAdapt — в алгоритме. На вход он получает четыре числа (вес, энергия, сон, настроение), на выходе — готовую рекомендацию: тип тренировки, интенсивность, длительность и текстовое объяснение.

Этот алгоритм можно встраивать в чужие продукты через API. Фитнес-клубу не нужно разрабатывать систему адаптации нагрузок с нуля: это долго, дорого и не их компетенция.

## Сегменты рынка

| Сегмент | Кто конкретно | Зачем им это |
|---|---|---|
| Сети фитнес-клубов | World Class, X-Fit, DDX, Spirit Fitness | Персонализация без найма физиологов, снижение оттока |
| Корпоративный велнес | HR-отделы, ДМС-операторы | Программы здоровья сотрудников, отчётность |
| Реабилитация | Медцентры, санатории | Контроль нагрузки при восстановлении после травм |
| Фитнес-приложения | Стартапы, независимые разработчики | Готовый модуль вместо разработки с нуля |

## Модель бизнеса: B2B2C

Проект продаёт решение партнёру (фитнес-клубу), партнёр встраивает его в своё приложение и предоставляет конечным пользователям.

| Звено | Роль |
|---|---|
| **FitAdapt** | Разрабатывает алгоритм, API, дашборд тренера |
| **Партнёр** | Интегрирует API в своё приложение, ведёт клиентов |
| **Пользователь** | Видит персональные рекомендации, не знает про FitAdapt |

## Условия платформизуемости

**Алгоритм универсален.** DMN-правила не зависят от конкретного клуба — только от числовых показателей.

**Данные принадлежат партнёру.** FitAdapt не хранит персональные данные конечных клиентов, только обезличенные метрики. Это упрощает соответствие 152-ФЗ.

**Интеграция стандартная.** REST + OpenAPI — для разработчиков партнёра это обычный API-сервис.

## Что получает партнёр

- REST API: передать метрики, получить рекомендацию
- Webhook: события о низком Readiness Index
- Дашборд тренера: iframe или white-label портал
- SDK для iOS и Android
- Sandbox-среда с генератором тестовых данных
- OpenAPI-спецификация и документация с примерами
