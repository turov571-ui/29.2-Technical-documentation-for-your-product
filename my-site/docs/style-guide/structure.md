# Структура документа

Каждая страница документации должна иметь единообразную структуру.

## Front matter

Каждый `.md` файл начинается с front matter:

```md
***
sidebar_position: 1
title: Название страницы
***
```

## Правила заголовков

- На странице — **один** заголовок уровня `#`.
- Основные разделы: `##`.
- Вложенные подразделы: `###`.
- Не пропускать уровни (нельзя перейти с `##` сразу на `####`).

## Имена файлов

- Используется `kebab-case`: `readiness-index.md`, `kafka-topics.md`.
- Имя файла отражает содержание страницы.
- `title` в front matter и имя файла согласованы по смыслу, но не обязаны совпадать дословно.

## Рекомендуемая структура страницы

1. **Назначение раздела** — 1–2 предложения, зачем эта страница существует.
2. **Основное содержимое** — таблицы, описания, схемы.
3. **Примеры** — JSON, код, диаграммы.
4. **Шаблон для развития** — `:::info Шаблон` с перечнем того, что будет добавлено позже.

## Callout-блоки

Docusaurus поддерживает callout-блоки:

```md
:::info Шаблон
Будет добавлено позже.
:::

:::note
Примечание.
:::

:::warning
Важное предупреждение.
:::
```
